# Contributing · Como contribuir

1. Run `python3 casc_audio.py score examples/manifest.csv examples/predictions.csv`.
2. Pick a [good first issue](https://github.com/henrivalle/casc-audio-lab/labels/good%20first%20issue), or open an issue describing what you tried and where you got stuck.
3. Run `python3 -m unittest discover -s tests -v` before opening a pull request.

Reports can include OS, Python version, model, language, error counts, and a synthetic reference that illustrates the problem. Use synthetic, public-domain, or properly licensed material in public reports.

1. Execute o exemplo do README. Ele funciona sem modelo e sem áudio.
2. Escolha uma [tarefa inicial](https://github.com/henrivalle/casc-audio-lab/labels/good%20first%20issue) ou abra uma issue com o comando executado e o resultado.
